# Patrick Flynn - EdTech Portfolio

Professional portfolio website for Patrick Flynn, EdTech Coach and Computer Science Teacher at British International School Hanoi.

## Website
[patrickflynnedtech.com](https://www.patrickflynnedtech.com/)

## Technology
- HTML, CSS, JavaScript
- Bulma CSS framework
- JSON content management
- Static site hosting

## Local Development
```bash
python -m http.server 8000
```

## Content Updates
Edit the JSON files in the `content/` folder:
- `home.json` - Main page content
- `about.json` - About page content
- `portfolio.json` - Projects and experience
- `contact.json` - Contact information
